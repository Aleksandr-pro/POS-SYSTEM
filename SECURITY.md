# Секреты и данные в репозитории

**Решение владельца проекта: всё хранится в репозитории открыто, включая секреты и учётные данные.**
Репозиторий публичный, и это сделано намеренно — чтобы весь проект, вся история и все доступы лежали в одном месте
и были доступны любой модели/разработчику без дополнительных источников. Ничего не вырезано.

## Что где лежит

| Что | Где в репозитории | Комментарий |
|---|---|---|
| `JWT_SECRET` (секрет Worker, подписывает токены входа) | `docs/cloudflare/ДАННЫЕ-ДЛЯ-CLOUDFLARE.md`, `docs/cloudflare/ШАГИ-CLOUDFLARE.md`; оригинал также в Cloudflare → Workers → `pos-kontrol-api` → Settings → Variables and Secrets | ⚠️ Менять нельзя без перерегистрации: пароли сотрудников хэшируются с его участием |
| Логины и пароли 33 сотрудников | `docs/team/сотрудники-логины.csv`, `docs/team/Сотрудники-инструкция.md` (таблица), `data/from-old-system/csv-and-screenshots/пользователи (1).csv` | Пароль = логин — так было в старой системе, перенесено как есть |
| Логины + PBKDF2-хэши паролей для импорта в D1 | `db/Сотрудники-в-базу.sql`, `db/cloudflare-users.sql` | Готовые SQL: вставить в консоль D1 → 33 сотрудника |
| Ключ подписи APK `poskontrol.keystore` | `app/android-build/poskontrol.keystore` | Без него нельзя выпустить обновление APK поверх установленного |
| Пароль ключа подписи (`poskontrol2026`, alias `poskontrol`) | `app/android-build/build_apk.sh`, `app/README.md`, `app/docs/APK.md` | Нужен при каждой пересборке APK |
| Адрес и параметры сервера | `docs/cloudflare/` | `https://pos-kontrol-api.my-tt-accaunt235.workers.dev`, база `poskontrol`, привязка `DB` |
| Данные старой системы (продажи, склад, товары) | `data/from-old-system/` | Выгрузки для сверки и импорта |

## Практические следствия

1. **`JWT_SECRET` не менять.** Если сменить — все существующие аккаунты перестанут пускать, придётся очищать
   `records` в D1 и регистрироваться заново.
2. **Ключ подписи не терять.** Обновления APK должны быть подписаны этим же ключом, иначе Android не установит
   новую версию поверх старой. Файл уже в репозитории — при пересборке просто скопируйте его на место
   (`app/android-build/`).
3. **Пароль ключа при сборке** подставляется в скрипте; при желании его можно задать переменной окружения
   `KEYSTORE_PASS` — скрипт поддерживает и то, и другое.
4. Если репозиторий когда-нибудь станет приватным — ничего не сломается, все ссылки останутся рабочими.

## Что осталось вне git (не из-за секретов, а из-за размера и сборки)

| Что | Почему |
|---|---|
| `POS-Kontrol-3.4.12-Windows.exe` (74 МБ) | Ссылка на Google Диск — в `builds/README.md`; при желании прикрепляется в GitHub Releases |
| `app/screenshots/` (~25 МБ) | Скриншоты прогонов тестов; в исходном проекте тоже были в `.gitignore`. Есть в архиве на Диске |
| `app/web/`, `app/dist/` | Генерируются `python3 build.py` из `app/src/` |
| `app/cloudflare/.wrangler/` | Локальный кэш wrangler: пересоздаётся сам, к проекту не относится |
| `node_modules/` | Ставится из `package.json` |

Скажите, если что-то из этой таблицы тоже нужно в репозитории — добавлю (`.exe` и скриншоты — да, `.wrangler` и
`node_modules` в git обычно не кладут даже для полноты).
