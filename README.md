# POS Контроль — 3.4.12

POS-система для магазинов: продажи, расходы, прибыль, склад, поставки, рабочее время продавцов и аналитика.
Работает **офлайн** на каждом устройстве, а при подключённом сервере — синхронизируется между всеми точками
через **Cloudflare Workers + D1**.

| | |
|---|---|
| Версия | **3.4.12** (26.11.2026) |
| Платформы | Windows (.exe), Android (.apk), iPhone / iPad (PWA через Safari), веб (один .html) |
| Стек | чистый JavaScript (ES5-совместимый), без сборщиков и CDN; Capacitor + Electron для нативных оболочек |
| Бэкенд | Cloudflare Worker `pos-kontrol-api` + база D1 `poskontrol` |
| Репозиторий | публичный; все файлы проекта, включая секреты, ключ подписи APK и учётки сотрудников, лежат здесь — см. [SECURITY.md](SECURITY.md) |

> **Моделям и разработчикам: начинайте с [PROJECT-STATUS.md](PROJECT-STATUS.md)** — там текущее состояние,
> что готово, что открыто и как проверять изменения.

## Быстрый старт

### Пользователю (ничего устанавливать не нужно)

| Устройство | Что делать |
|---|---|
| Windows 10/11 | `POS-Kontrol-3.4.12-Windows.exe` — 74 МБ, лежит на Google Диске (ссылка в [builds/README.md](builds/README.md)) → «Подробнее» → «Выполнить в любом случае». Подробнее: [docs/install/Windows-как-запустить.md](docs/install/Windows-как-запустить.md) |
| Android | Открыть [builds/POS-Kontrol-3.4.12.apk](builds/POS-Kontrol-3.4.12.apk) на телефоне и установить |
| iPhone / iPad | Открыть ссылку сайта **в Safari** → «Поделиться» → «На экран „Домой“». Подробнее: [docs/install/iPhone-пошаговая-установка.md](docs/install/iPhone-пошаговая-установка.md) |
| Компьютер без установки | Открыть [builds/POS-Контроль-3.4.12.html](builds/POS-Контроль-3.4.12.html) в Chrome |

Общая база для всех точек — по инструкции [docs/cloudflare/ШАГИ-CLOUDFLARE.md](docs/cloudflare/ШАГИ-CLOUDFLARE.md).

### Разработчику

```bash
cd app
python3 build.py          # собирает web/ и dist/index.html
npm run serve             # http://localhost:8080

npm run test:e2e          # 31 проверка в реальном Chromium
npm run test:sandbox      # работа в песочнице без localStorage
```

Первый вход: кнопка «Открыть демо-версию» на экране входа (демо: `demo / demo123`) либо «Зарегистрироваться» —
первый зарегистрированный пользователь становится администратором.

Сборка APK — `bash app/android-build/build_apk.sh` (нужен `KEYSTORE_PASS`, см. [SECURITY.md](SECURITY.md)).
Сборка Windows-версии — `bash app/desktop/build-windows.sh`.

## Возможности

| Раздел | Что умеет |
|---|---|
| Панель | выручка, расходы, прибыль, средний чек за день/неделю/месяц, сравнение периодов, графики, разбивка оплат, топ товаров |
| Касса | каталог с поиском, остатки, корзина, наличные / Kaspi QR / смешанная оплата, фото чека для QR |
| Товары | категории, фото, цены, привязка к точкам, остатки, экспорт в Excel |
| Склад | остатки по точкам, быстрые +/−, история с сотрудником и датой, статусы «заканчивается / нет», поставки |
| Точки продаж | адрес, координаты, вкладки «Пользователи» и «Склад» |
| Пользователи | роли (админ / разработчик / продавец), точки, график, сброс пароля, импорт из CSV |
| Время | приход/уход с геолокацией, таймер смены, табель, геометки на карте, экспорт |
| Аналитика | KPI с динамикой, структура оплат, топ товаров, продажи по точкам, расходы по статьям, рейтинг сотрудников |
| Настройки | темы (светлая/тёмная/системная), профиль, резервная копия JSON, сервер и синхронизация, демо-данные |

Подробное описание архитектуры и каждой функции — [app/README.md](app/README.md).
