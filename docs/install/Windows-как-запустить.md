# POS Контроль — версия для Windows

**Файл:** `POS-Kontrol-3.4.11-Windows.exe` (72 МБ)

## Как запустить

1. Скачайте `.exe` на компьютер с Windows 10 или 11 (64-бит).
2. Двойной клик по файлу.
3. Windows может показать синее окно **«Система Windows защитила ваш компьютер»** — это нормально для программ без платной цифровой подписи.
   Нажмите **«Подробнее»** → **«Выполнить в любом случае»**.
4. Установка не нужна: программа работает из этого файла.

## Что внутри

- Полная версия приложения: панель, касса, товары, склад, ручные продажи, время, аналитика, настройки.
- Компьютерный интерфейс: сворачиваемое меню, поиск **Ctrl+K**, экспорт в шапке страницы.
- Горячие клавиши: `Ctrl+K` — поиск, `Ctrl+B` — свернуть меню, `Alt+1…9` — разделы, `F11` — полный экран.

## Где хранятся данные

На этом компьютере, отдельно для каждого пользователя Windows:

```
C:\Users\<Имя>\AppData\Roaming\POS Контроль\
```

Меню **Файл → Открыть папку данных** открывает её.

## Экспорт в Excel

Кнопка «Экспорт» → откроется окно «Сохранить файл» → выберите папку.
Файл `analitika_*.xlsx` открывается в Excel.

## Перенос с телефона

Данные в компьютере и на телефоне — раздельные. Чтобы вести общий учёт:
Настройки → Сервер и синхронизация → адрес Worker и вход под тем же логином.

## Пересборка (для разработчика)

```bash
cd pos-app/desktop
bash build-windows.sh
```

Нужны: Node.js 20+, wine + xvfb (на Linux) — только для сборки, не для запуска.
