# iPhone — самый простой путь

## Вариант 1 (совсем без действий): я загружу сам

1. В чате включите приложение **Vercel** (тумблер в подключённых приложениях).
2. Напишите: «включил».
3. Я загружу приложение и пришлю ссылку.
4. На iPhone откройте ссылку в Safari → **Поделиться** → **На экран «Домой»**.

Всё. Ничего скачивать и никуда перетаскивать не нужно.

---

## Вариант 2 (если хотите сами, 4 действия)

1. Зайдите на **vercel.com** и войдите через Google.
2. **Add New… → Project → Deploy** — или просто перетащите папку из архива `POS-Kontrol-3.4.12-iOS.zip` на страницу **vercel.com/new**.
3. Дождитесь надписи **Congratulations** и скопируйте ссылку проекта.
4. Откройте её в Safari на iPhone → **Поделиться** → **На экран «Домой»**.

---

## Что дальше

Иконка **POS Контроль** появится на домашнем экране.
Открывается на весь экран, без адресной строки, работает без интернета.
Вход — вашим логином (как на Android и на компьютере).
