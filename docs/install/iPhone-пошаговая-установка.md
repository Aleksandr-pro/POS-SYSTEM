# POS Контроль на iPhone

## Коротко

На iPhone приложение ставится с сайта на домашний экран — выглядит и работает как обычное приложение: своя иконка, без адресной строки, работает без интернета.

Файл для загрузки: POS-Kontrol-3.4.12-iOS.zip (294 КБ) — лежит в папке «1. Приложение».

---

## Почему не файл .ipa

Приложения для iPhone нельзя просто «скинуть файлом», как APK на Android. Apple разрешает установку только через:

- App Store — нужен аккаунт разработчика Apple Developer, 99 $/год и проверка у Apple;
- TestFlight — тот же аккаунт;
- подпись на конкретные устройства — тоже аккаунт и компьютер Mac с Xcode.

Без этого аккаунта ни один .ipa не установится. Поэтому для iOS делаем веб-приложение: тот же код, тот же вид, работает офлайн. Когда появится аккаунт Apple — из этой же сборки собирается .ipa без переделки.

## Шаг 1. Загрузить на Cloudflare Pages

1. Откройте dash.cloudflare.com → слева Workers & Pages.
2. Create → вкладка Pages → Upload assets.
3. Название проекта: pos-kontrol → Create project.
4. Перетащите содержимое архива POS-Kontrol-3.4.12-iOS.zip: index.html, core.js, styles.css, папку icons и остальные файлы.
5. Deploy site.
6. Получите адрес вида: https://pos-kontrol.pages.dev

Проверка: откройте адрес на компьютере — должен появиться экран входа.

---

## Шаг 2. Поставить на iPhone

1. Откройте ссылку в Safari (именно Safari, не Chrome).
2. Нажмите кнопку «Поделиться» — квадрат со стрелкой вверх, внизу по центру.
3. Пролистайте → «На экран „Домой“» → Добавить.
4. На домашнем экране появится иконка POS Контроль.

Всё. Запускается с иконки, без адресной строки, на весь экран.

---

## Шаг 3. Войти

Логин и пароль те же, что на телефоне Android и на компьютере.

Если база на Cloudflare уже настроена (Worker pos-kontrol-api):
Настройки → Сервер и синхронизация → адрес Worker → войти под своим логином.
Тогда iPhone, Android и компьютер показывают одни и те же продажи.

---

## Что уже сделано под iPhone

- поддержка «выреза» и домашнего индикатора (safe area) — ничего не перекрывается;
- поля ввода не вызывают автоматический зум при наборе;
- нет синей подсветки при нажатии;
- отключён «резиновый» отскок страницы;
- иконка 180×180 для домашнего экрана;
- тёмная тема подхватывается от системной;
- офлайн-кеш: приложение открывается без интернета, данные сохраняются в памяти телефона;
- мастер установки: кнопка «Установить» в шапке с четырьмя шагами;
- жёлтая рамка-подсказка, если открыто в Safari не с домашнего экрана;
- экспорт в Excel работает.

---

## Обновление приложения

Загрузите новые файлы в тот же проект Cloudflare Pages (Create new deployment → Upload assets).
На iPhone откройте приложение — обновится само при следующем запуске. Данные не пропадут.

---

## Если нужен именно .ipa

Понадобится:
1. Аккаунт Apple Developer (99 $/год).
2. Mac с Xcode (или облачная сборка Codemagic / GitHub Actions с macOS).
3. Сборка через Capacitor:

cd pos-app
npx cap add ios
npx cap sync ios
npx cap open ios

Дальше в Xcode: Team → Bundle ID kz.poskontrol.app → Archive → TestFlight или App Store.
Код приложения менять не нужно — Capacitor заворачивает уже готовую папку web/.
