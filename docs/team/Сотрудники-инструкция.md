# Сотрудники из старой системы — 33 человека

Логины и пароли перенесены как в файле: **пароль = логин** (кроме тех, где в файле было иначе).

## 1. Занести в облачную базу Cloudflare (главное)

Консоль D1 на телефоне выполняет **одну команду за раз** — поэтому весь список уже собран в одну команду.

1. <https://dash.cloudflare.com> → **Workers & Pages** → **D1 SQL Database** → база **poskontrol** → вкладка **Console**.
2. Откройте файл **`cloudflare-users-one-query.sql`**, скопируйте его **целиком** (одна команда INSERT на всех 33).
3. Вставьте в окно и нажмите **Execute**.
   Ответ «This query returned no data» — это нормально: команда вставляет данные, а не показывает их.
4. Проверка — отдельной командой:
   ```sql
   SELECT COUNT(*) AS cnt FROM records WHERE collection = 'users';
   ```
   Должно вернуться **33** (или больше, если в базе уже были другие пользователи).

Файл можно запускать повторно — сотрудники с такими логинами второй раз не добавятся.

## 2. Или занести из приложения (офлайн-устройство)

1. Обновите приложение до **3.4.5**.
2. «Точки продаж» → вкладка **Пользователи** → кнопка **Импорт из CSV**.
3. Выберите файл `пользователи (1).csv` (или вставьте строки в поле).
4. Проверьте предпросмотр → **Импортировать**.

## 3. После импорта — раздать точки

Продавец без точки не может открыть кассу: «Точки продаж» → **Пользователи** → карандаш у сотрудника → отметить его точку(и) → Сохранить.

Пять точек: Керуен, Sky, My Kids, Dalida Plaza, Elegant Park.

## Список логинов

Реальные логины и пароли всех 33 сотрудников **не хранятся в этом репозитории** (он публичный).
Они лежат в Google Диске: папка **«3. База и Cloudflare»** → файл `сотрудники-логины.csv`,
и в самой базе D1 (`records`, collection = `users`) — там пароли в виде PBKDF2-хэша.

В репозитории есть только формат файла: `docs/team/сотрудники-логины.example.csv`
(имя, логин, роль, пароль, ID в базе — со значениями-заглушками).

Занести сотрудников в облако можно одним запросом из файла `db/Сотрудники-в-базу.sql`
(он содержит хэши, а не пароли, поэтому безопасен для хранения).

Все 33 — роль **Продавец**. Пароли в базе хранятся в виде PBKDF2-хэша с секретом сервера — в открытом виде их нет.
