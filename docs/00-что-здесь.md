# POS Контроль — рабочее пространство

Версия приложения: 3.4.12 (iPhone, Android, Windows, веб).

1. ПРИЛОЖЕНИЕ — готовые файлы
- POS-Kontrol-3.4.12-Windows.exe — Windows, просто запустить. Первый запуск: «Подробнее» → «Выполнить всё равно».
- POS-Kontrol-3.4.12.apk — Android, открыть на телефоне и установить.
- POS-Kontrol-3.4.12-iOS.zip — iPhone: архив сайта, положить на хостинг (Vercel или Cloudflare Pages), открыть ссылку в Safari и нажать «На экран Домой».
- POS-Контроль-3.4.12.html — компьютер без установки, открыть в Chrome.
- pos-app-source-3.4.12.zip — исходники проекта (src, ios-build, desktop, android-build, test).

2. ИНСТРУКЦИИ
- iPhone — почему и как.md — почему нет файла .ipa и три способа поставить на iPhone.
- iPhone — пошаговая установка.md — Cloudflare Pages + 4 шага в Safari.
- Windows — как запустить.md — SmartScreen, данные, пересборка.
- Сотрудники — инструкция.md — логины и обучение продавцов.
- Сайт — как загрузить.md — публикация iOS-сборки.

3. БАЗА И CLOUDFLARE
- CLOUDFLARE — обзор.md — архитектура: Worker, D1, доступы.
- ШАГИ-CLOUDFLARE.md — пошагово в панели, можно с телефона.
- ДАННЫЕ-ДЛЯ-CLOUDFLARE.md — все значения для копипаста и таблица ошибок.
- СХЕМА-БД.sql — создать таблицы.
- Сотрудники в базу.sql — все сотрудники одним запросом.
- сотрудники-логины.csv — логины и пароли.
- база-worker-sql-и-данные.zip — код Worker + схема + SQL + описание данных.

4. ДАННЫЕ ИЗ СТАРОЙ СИСТЕМЫ
- данные-из-старой-системы.zip — отчёты склада по дням (xlsx), CSV товаров и точек, скриншоты.
- 1-октября-2026 (продажи из старой системы).txt — выгрузка продаж за 1 октября.

ПОРЯДОК С НУЛЯ
1. Поставить Windows.exe или APK и войти.
2. По ШАГИ-CLOUDFLARE.md поднять базу, чтобы данные были общие для всех точек.
3. Загрузить POS-Kontrol-3.4.12-iOS.zip на хостинг и раздать ссылку продавцам с iPhone.

Важно: в Google Диске хранятся только файлы. Само приложение с Диска не запускается — для iPhone нужен хостинг, для Windows и Android — файлы из папки «1. Приложение».
