# Готовые сборки 3.4.12

| Файл | Для чего | Размер |
|---|---|---|
| `POS-Kontrol-3.4.12.apk` | Android: скинуть на телефон и установить (разрешить установку из неизвестных источников) | 487 КБ |
| `POS-Контроль-3.4.12.html` | Компьютер без установки: открыть в Chrome, работает даже через `file://` | 837 КБ |
| `POS-Kontrol-3.4.12-iOS.zip` | iPhone: архив сайта для хостинга (Vercel / Cloudflare Pages), потом «Поделиться» → «На экран „Домой“» | 301 КБ |

## Windows (.exe)

`POS-Kontrol-3.4.12-Windows.exe` — **74 МБ**, в git не хранится (слишком большой файл).
Лежит в разделе **Releases**:

https://github.com/Aleksandr-pro/POS-SYSTEM/releases/tag/v3.4.12

Первый запуск: Windows покажет «Система Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
Подробнее — [../docs/install/Windows-как-запустить.md](../docs/install/Windows-как-запустить.md).
