## Windows (.exe)

`POS-Kontrol-3.4.12-Windows.exe` — **74 МБ**. В git такие файлы не кладут (репозиторий распух бы в 20 раз),
поэтому он лежит в двух местах:

1. **Google Диск** — папка «1. Приложение»:
   https://drive.google.com/file/d/1w1W6prePFylzugjWGDDwDEbJnnEgIJP5/view
2. **GitHub Releases** — при желании файл можно прикрепить сюда вручную
   (Releases → Draft a new release → тег `v3.4.12` → перетащить `.exe`).

Пересобрать самому:

```bash
cd app/desktop
bash build-windows.sh      # нужны Node.js 20+, на Linux — wine + xvfb
```

Первый запуск: Windows покажет «Система Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
Подробнее — [../docs/install/Windows-как-запустить.md](../docs/install/Windows-как-запустить.md).
