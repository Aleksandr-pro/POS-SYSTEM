# POS Контроль 2.0

Полнофункциональная POS-система по вашему ТЗ: контроль продаж, расходов, прибыли, склада и рабочего времени продавцов. Работает **офлайн**, данные хранятся на устройстве. Готова к упаковке в APK и к подключению Cloudflare (сервер + база).

## Что внутри

| Раздел | Возможности |
|---|---|
| **Вход / регистрация** | Проверка уникальности логина в реальном времени, индикатор надёжности пароля, показ/скрытие пароля, условия использования. Роли по порядку: 1-й → администратор, 2-й → разработчик, остальные → продавцы |
| **Панель** | Выручка, расходы, прибыль, средний чек за сегодня / неделю / месяц, сравнение с предыдущим периодом, график выручки и расходов, донат способов оплаты, топ товаров, последние транзакции с чеками и удалением |
| **Касса** | Каталог с категориями и поиском, контроль остатков, корзина, наличные / Kaspi QR / смешанная оплата, обязательное фото чека для QR, продажи и расходы за день |
| **Товары** | Карточки с фото, категории (создание/удаление), цена, привязка к точкам, остатки, экспорт в Excel |
| **Склад** | Остатки по каждой точке, быстрые +/−, история изменений с сотрудником и датой, статусы «заканчивается / нет», экспорт |
| **Точки продаж** | Создание точек с адресом и координатами (определение геопозиции), вкладки «Пользователи» и «Склад» |
| **Пользователи** | Создание, редактирование, смена роли, точки, графика, сброс пароля, удаление (транзакции сохраняются, последнего админа удалить нельзя) |
| **Время** | Приход/уход с геолокацией, живой таймер смены, история за 7 дней, табель всех сотрудников на дату, геометки на карте, экспорт |
| **Аналитика** | KPI с динамикой, график, структура оплат, топ товаров с долями, продажи по точкам, расходы по статьям, рейтинг сотрудников |
| **Помощь** | Интерактивное руководство по всем разделам, роли, советы, контакты разработчика, план синхронизации |
| **Настройки** | Оформление (светлая / тёмная / системная тема), профиль, смена пароля, контакты разработчика, размер базы, резервная копия JSON (скачать/восстановить), демо-данные, сброс |

Особенности:
- **Тёмная тема**: переключатель в шапке и на экране входа, выбор «светлая / тёмная / системная» в настройках, запоминается на устройстве; графики и системные панели Android подстраивают цвета.
- **Офлайн-first**: полностью работает без интернета, localStorage + защита от переполнения.
- **Экспорт в Excel**: настоящий `.xlsx` (не CSV) с несколькими листами, шапкой и автофильтрами — собственный генератор `src/xlsx.js`, без внешних библиотек.
- **Автоочистка**: чеки и детали расходов удаляются через 7 дней, статистика остаётся.
- **Геолокация**: в отметках времени и точках продаж; при отказе доступна отметка без геометки.
- **Роли и права**: продавец не видит аналитику/товары/точки и работает только со своей точкой.
- **Демо-данные**: 2 точки, 12 товаров, продажи за 14 дней, демо-продавец `aigul / 123456`.
- **Мобильный интерфейс**: нижняя навигация, bottom-sheet модалки, адаптивная касса.

## Быстрый запуск

```bash
cd pos-app
python3 build.py          # собирает web/ и dist/index.html
npm run serve             # http://localhost:8080
```

Открыть `web/index.html` можно и просто через локальный сервер (нужен для service worker и корректной работы модулей).

**Первый вход:** два варианта
- нажмите **«Открыть демо-версию»** на экране входа — сразу загрузится база с продажами и двумя точками (вход `demo / demo123`);
- или **«Зарегистрироваться»** — первый пользователь станет администратором и настроит всё под себя.

## APK

Готовый файл: **`dist/POS-Kontrol-2.1.0.apk`** (388 КБ, подписан v1+v2+v3).

Сборка выполняется без Gradle — скриптом `android-build/build_apk.sh`
(`aapt2` → `javac` → `d8` → `zipalign` → `apksigner`):

```bash
python3 build.py                     # веб-часть
bash android-build/build_apk.sh      # APK в dist/
```

Что делает нативная оболочка (`android-build/src/...`):
- грузит `assets/www/index.html` в WebView — **полностью офлайн**, без сервера;
- `AndroidPos`-мост: экспорт Excel/JSON (сохранение файла + «Поделиться»), синхронизация цвета системных панелей с темой, тосты;
- выбор фото из галереи **и съёмка на камеру** для чеков и товаров;
- разрешение геолокации при первом запуске (для отметок прихода/ухода);
- кнопка «Назад» сначала закрывает модальные окна и возвращает по разделам;
- splash-экран с логотипом, adaptive-иконка, тёмная и светлая темы системных панелей.

Ключ подписи: `android-build/poskontrol.keystore`, alias `poskontrol`, пароль `poskontrol2026`.
**Сохраните его** — обновления APK должны быть подписаны тем же ключом, иначе Android не установит новую версию поверх.

Подробная инструкция, включая сборку через Android Studio и GitHub Actions — `docs/APK.md`.

## Облако — Cloudflare (готово)

В приложении есть полноценная синхронизация через Cloudflare Workers + D1:

- `cloudflare/worker.js` — API: регистрация, вход, роли (админ/разработчик/продавец), синхронизация, управление пользователями;
- `cloudflare/schema.sql` — таблицы `records`, `meta`, `audit_log`;
- `src/api.js` — клиент: офлайн-очередь, автосинхронизация, статус в шапке;
- **Настройки → Сервер и синхронизация** — адрес сервера, вход, статус, ручная синхронизация.
- **Несколько точек у сотрудника**: в карточке пользователя отмечаются все доступные точки,
  продавец переключается между ними в шапке; продажи, расходы и остатки каждой точки не смешиваются.
- **Разбивка оплат**: в кассе, на панели и в аналитике показывается общая сумма смешанных оплат
  и отдельно — сколько поступило наличными и сколько через Kaspi QR.

Пошаговая инструкция по развёртыванию (веб-панель Cloudflare или wrangler) — `docs/CLOUDFLARE.md`.

## Технические детали

- Чистый JavaScript (ES5-совместимый синтаксис) — работает в старых Android WebView без сборщиков.
- Никаких CDN и внешних запросов: шрифты системные, иконки — inline SVG, графики — canvas.
- Пароли — SHA-256 через Web Crypto (fallback — FNV-хэш), в базе хранится только хеш.
- Фото товаров и чеков сжимаются в canvas до ~720 px / 68–72 % JPEG.
- Экспорт Excel реализован вручную: ZIP без сжатия + SpreadsheetML, CRC32.
