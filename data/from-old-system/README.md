# Данные из старой системы

Выгрузки, снятые со старой POS-системы до перехода на «POS Контроль». Нужны для сверки остатков,
истории продаж и импорта товаров.

| Папка/файл | Что внутри |
|---|---|
| `reports-stock/` | отчёты склада по дням, `.xlsx` (19–23.10.2026, 14.11.2026), по несколько копий за день |
| `csv-and-screenshots/` | CSV товаров по точкам (`Dalidaplaza.csv`, `Elegantpark.csv`, `Аквагримкеруен.csv`, `Гипсmykids.csv`, `Гипсsky.csv`) + скриншоты из старой системы |
| `1-октября-2026-продажи.txt` | текстовая выгрузка продаж за 1 октября 2026 |

Импорт в приложение: «Товары» / «Склад» → импорт из CSV, либо `app/src/import-data.js` (импорт данных старой системы).
